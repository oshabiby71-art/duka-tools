# Contributing to DukaTools

Thanks for helping make small-shop tools more useful.

## Before you start

- Open an issue first for a larger feature so the need can be discussed.
- For a small fix, a pull request is welcome.
- Keep changes lightweight, accessible, and usable on mobile browsers.
- Preserve the offline-first design. Do not transmit shop data or add analytics without clear, informed consent.
- Describe the problem your change solves and how someone can use it.

## Pull requests

Keep each pull request focused. Include screenshots for visible interface changes and note the browsers or devices you used to check them. Be respectful and constructive in discussions.
